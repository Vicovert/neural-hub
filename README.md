# neural-hub

Neural Dev Hub V5.4 — Moteur 3D, GitHub Git Data API & Routeur Multi-Agents.

## Description
Plateforme de visualisation de dépôts GitHub sous forme de cerveau 3D interactif avec intégration d'intelligences artificielles (Gemini, Groq, Ollama).

## Installation
1. Cloner le dépôt
2. Installer les dépendances : `npm install`
3. Lancer les tests : `npm test`

## Utilisation
Ouvrez `index.html` dans un navigateur moderne ou servez le dossier via un serveur statique.
